# 2026 Competition Robot Codes

Robot code for all 2026 competitions. Each sketch is the full firmware for that event, covering LoR Core V3, MiniBot, and any auxiliary systems.

Carried over from the 2025 archive so old setups are easy to reference and pull snippets from.

## Sketches

- `MiniBot_Competition1.ino` - MiniBot for competition 1. Starts from the 2025 comp 4 code with the drive sides swapped (slots 1-3 right, 4-6 left) and both drive axes inverted to match the new motor mounting.
